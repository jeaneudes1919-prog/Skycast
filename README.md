# Skycast

Application météo en direct : ambiance visuelle qui change selon le temps et l'heure (pluie, neige, orage, étoiles, soleil), recherche de villes avec autocomplétion, prévisions sur 24 heures et 7 jours, détails (humidité, vent, UV, soleil), villes favorites, °C/°F, mode hors ligne.

**Stack** : React 18, Vite 5, Tailwind CSS 3, Framer Motion. Données : [Open-Meteo](https://open-meteo.com) (gratuit, sans clé API).

```bash
npm install
npm run dev
npm run build
```
